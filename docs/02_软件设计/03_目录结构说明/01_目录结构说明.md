# 渲染进程目录结构说明

本文档说明 `src/renderer/` 路径下各文件夹及关键文件的作用。

## 目录树

```text
src/renderer/
├── index.html                      ← 渲染进程的 HTML 入口
└── src/
    ├── main.ts                     ← 渲染进程的 JS 入口
    ├── App.vue                     ← 根组件
    ├── env.d.ts                    ← Vite 客户端类型声明
    ├── styles.css                  ← 基础重置样式
    │
    ├── assets/                     ← 静态资源目录
    │   ├── fonts/                  ← 字体文件
    │   └── styles/                 ← 全局样式
    │
    ├── components/                 ← 公共组件目录
    │
    ├── router/                     ← 路由目录
    │   └── index.ts                ← 路由配置
    │
    └── views/                      ← 页面视图目录
        └── import_view/            ← "导入项目"页面
            ├── ImportProject.vue
            ├── ImportProject.css
            └── useImportProject.ts
```

## 各文件夹职责

| 文件夹 | 作用 |
| --- | --- |
| `assets/fonts/` | 存放自定义字体文件（如 Noto Sans SC 可变字重 TTF） |
| `assets/styles/` | 存放全局样式，包括字体声明（`font.css`）和设计稿导出的工具类（`global.css`） |
| `components/` | 存放可复用的公共 UI 组件（目前为空，后续添加通用组件） |
| `router/` | 路由配置中心，定义页面路由表、导航方式（hash 模式）及 guid→path 映射工具 |
| `views/` | 页面级组件，每个子文件夹对应一个完整页面 |

## 关键文件说明

### 入口文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 渲染进程 HTML 入口，挂载 `#app` 容器并引入 `main.ts` |
| `main.ts` | 渲染进程 JS 入口：导入全局样式、创建 Vue 实例、挂载路由 |
| `App.vue` | 根组件，仅包含 `<router-view>` 作为页面出口 |
| `env.d.ts` | Vite 客户端类型声明，让 TypeScript 识别 `import.meta` 等 API |
| `styles.css` | 基础重置样式：清除 margin/padding，设定 body 和 #app 全屏 |

### assets/styles/ 全局样式

| 文件 | 作用 |
| --- | --- |
| `font.css` | `@font-face` 声明，注册 Noto Sans SC 自定义字体 |
| `global.css` | 全局工具类（Pixso 设计稿导出的布局、透明、弹性盒等通用 class） |

### views/ 页面视图

每个页面采用 **三件套** 的模块化写法：

| 文件 | 作用 |
| --- | --- |
| `ImportProject.vue` | 页面组件（模板结构 + 逻辑绑定） |
| `ImportProject.css` | 页面专属样式 |
| `useImportProject.ts` | 组合式函数（composable）：画布自适应缩放（1920×1080 基准）+ 文件选择/拖入逻辑 |

## 设计约定

- 项目采用固定 **1920×1080** 设计画布作为布局基准，所有 UI 元素使用绝对像素定位。
- 页面通过 `useImportProject.ts` 中的 `ResizeObserver` 实现等比缩放适配。
- 路由使用 `createWebHashHistory` 模式，适配 Electron 的 `file://` 协议。
- `views/` 下新增页面时，应遵循 **组件 + 样式 + 组合式函数** 的三件套结构。
