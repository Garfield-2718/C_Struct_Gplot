# 目前electron主进程设计中会涉及到的接口

目前项目设计依赖于`C_Struct_Gplot_CLI`来作为底层模块,本项目也就是`C_Struct_Gplot`仅仅作为一个`ui`渲染和用户交互的作用

关于`C_Struct_Gplot_CLI`项目的源码在`/home/wsl/code/C_Struct_Gplot_CLI`中存放,已经由`qoder`生成了`repo wiki`

## 与DB交互涉及的接口

### 按照名称读取元素信息

按照结构的名称(带有类型定义的完整名称)读取`db`中对应的`ui_json`字段,这里主要是用户手动搜索导入时候使用,导入时需要对于找到的ui_json字段中记录的每个子节点和父节点都去按照其hash再提取其名称

### 按照hash读取元素信息

按照`hash`去读取`db`中的`ui_json`字段,这里是和读取名称信息配合使用,因为`ui_json`字段中对于当前节点的子节点和父节点的记录是按照`hash`来存储的,为了用户号可以直接看到子节点和父节点的名称,需要按照其`hash`提取`ui_json`字段,然后通过其表头的数据读取其结构名称,用于用户的显示

### 导出指定元素接口

这里直接调用`C_Struct_Gplot_CLI`项目的导出接口
