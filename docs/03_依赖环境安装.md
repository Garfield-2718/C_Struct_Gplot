# 依赖环境安装清单

> 本文档整理构建 C_Struct_Gplot 所需安装的全部依赖环境，与《02_软件设计/05_构建方法/01_构建方法.md》第 2 节「前置依赖」对应，并补充 Windows 11 本机实测经验（2026-09 实测：Node v24.19.0 / npm 11.17.0 / Python 3.13.14 / PyInstaller 6.21.0，`npm run dist:win` 全流程构建通过）。

---

## 1. 依赖总览

| 依赖           | 实测版本（最低要求）                     | 用途                                        | 何时需要                          |
| -------------- | ---------------------------------------- | ------------------------------------------- | --------------------------------- |
| **Node.js**    | v24.19.0（文档实测 v22 可用，建议 ≥ v22）| Electron 应用构建与运行时                    | 始终必需                          |
| **npm**        | 11.17.0（随 Node.js 附带）               | 安装依赖、执行 `package.json` scripts        | 始终必需                          |
| **git**        | 任意较新版本                             | `build:cli` / `dist:*` 拉取 CLI 源码仓库      | 构建 CLI sidecar 时必需           |
| **Python 3**   | 3.13.14                                  | 运行 CLI 打包脚本 `build_package.py`         | 构建 CLI sidecar 时必需           |
| **pip**        | 随 Python 附带                           | 安装 PyInstaller                             | 构建 CLI sidecar 时必需           |
| **PyInstaller**| 6.21.0                                   | 将 CLI 打成单文件二进制 `struct_topology.exe`| 构建 CLI sidecar 时必需           |

> **说明**：仅执行 `npm run dev`、`npm run build`、`npm run build:win` 等应用类命令（不含 CLI）时，**无需** git / Python / pip / PyInstaller；只有 `build:cli` 与 `dist:win` / `dist:linux` 需要。
>
> `npm install` 的 `postinstall` 会自动执行 `electron-builder install-app-deps` 重建原生依赖，无需手动干预。

## 2. Windows 安装方法

### 2.1 Node.js

1. 从官网 <https://nodejs.org/> 下载 **LTS** 安装包（v22 或更高）。
2. 安装时保持默认选项（自动加入 PATH）。
3. 验证：

```powershell
node -v    # 实测输出：v24.19.0
npm -v     # 实测输出：11.17.0
```

### 2.2 git

`scripts/build-cli.mjs` 会执行 `git clone` 拉取 CLI 源码仓库（`https://github.com/Garfield-2718/C_Struct_Gplot_CLI.git`），本机必须安装 git 且能访问 GitHub。

1. 从官网 <https://git-scm.com/download/win> 下载安装。
2. 验证：

```powershell
git --version
```

### 2.3 Python 3

`build-cli.mjs` 在 Windows 上通过 **`python`** 命令（Linux/WSL 为 `python3`）调用 Python，请确保 `python` 在 PATH 中。

1. 从官网 <https://www.python.org/downloads/windows/> 下载 Python 3（实测 3.13.x 可用）。
2. 安装时**务必勾选 "Add python.exe to PATH"**。
3. 验证：

```powershell
python --version           # 实测输出：Python 3.13.14
python -m pip --version
```

### 2.4 PyInstaller

以用户级安装（不需要管理员权限）：

```powershell
python -m pip install --user pyinstaller
```

验证：

```powershell
python -m PyInstaller --version   # 实测输出：6.21.0
python -c "import PyInstaller"    # build-cli.mjs 的探测方式
```

> `build-cli.mjs` 构建前会主动探测 PyInstaller（执行 `python -c "import PyInstaller"`），缺失时只打印安装指引并以退出码 1 退出，**不会自动安装**。

## 3. 国内镜像配置（可选，强烈推荐）

Electron 二进制与 electron-builder 工具链默认从 GitHub 下载，国内网络容易超时失败。**注意：npm 11 已不支持 `npm config set electron_mirror`**（报错 `electron_mirror is not a valid npm option`，构建方法文档 2.1 节的该方法已失效），请改用**环境变量**。

PowerShell（当前会话生效，建议在执行 `npm install` / `dist:win` 前设置）：

```powershell
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR = 'https://npmmirror.com/mirrors/electron-builder-binaries/'
```

| 环境变量                            | 作用                                        |
| ----------------------------------- | ------------------------------------------- |
| `ELECTRON_MIRROR`                   | 加速 Electron zip 下载（npm install / 打包）|
| `ELECTRON_BUILDER_BINARIES_MIRROR`  | 加速 nsis / winCodeSign 等打包工具下载      |

> 若 `npm install` 因下载缓慢被超时终止，配置镜像后**直接重跑 `npm install`** 即可续装。

## 4. 环境自检（一键检查）

在项目根目录执行以下命令，全部有正常输出即环境就绪：

```powershell
node -v
npm -v
git --version
python --version
python -c "import PyInstaller; print('PyInstaller', PyInstaller.__version__)"
```

## 5. Linux / WSL 参考（在 Linux 上构建时）

仅当需要在 Linux/WSL 本机构建 Linux 版本时参考；Windows 构建无需以下任何步骤。

### 5.1 Electron 所需系统库

```bash
sudo apt install -y build-essential libgtk-3-dev libnotify-dev \
  libnss3 libxss1 libasound2t64 libxtst6
```

### 5.2 CLI sidecar 构建依赖

```bash
# 1) 安装 pip 与 venv
sudo apt-get install -y python3-pip python3-venv

# 2) 以用户级安装 PyInstaller
python3 -m pip install --user pyinstaller

# 3) 验证
python3 -m PyInstaller --version
```

> **PEP 668 提示**：若第 2 步报 `externally-managed-environment`（新版 Debian/Ubuntu 常见），追加 `--break-system-packages`。

## 6. 注意事项

1. **PyInstaller 不能交叉编译**：Windows 二进制只能在 Windows 本机产出（`dist:win` 的 `--target` 守卫会拦截跨平台误打包）。
2. **electron-builder EPERM 报错（Windows）**：electron-builder 26.15.3 在 Windows 打包时，Electron 解压目录改名处可能报 `EPERM: operation not permitted`（解压目录被瞬时句柄锁占用所致）。**无需修改 `node_modules` 或应用任何补丁，直接重新执行打包命令即可通过**。
3. **镜像配置必须用环境变量**：npm 11 起 `npm config set electron_mirror` 已失效（见第 3 节）。
